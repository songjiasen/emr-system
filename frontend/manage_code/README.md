# manage_code

后台管理端前端项目，负责管理员、医生、护士、主任等角色的工作台和管理页面。

## 当前实现范围

- 后台登录、注销、Token 校验和登录态恢复。
- 预约管理、科室管理、多角色用户管理。
- 分诊建档、入院登记、出院办理。
- 病历录入、病历模板、病历归档申请和归档审核。
- 医嘱、处方、检查申请、医嘱执行和审核结果展示。
- 工作流审核任务、审核记录、费用管理、资讯管理、留言回复、轮播图、菜单配置、操作日志。
- AI OCR、智能荐药、处方审核和智能检索演示入口。

## 接口与会话

- 前端统一通过网关前缀 `/cl584734139` 访问后端。
- 登录成功后保存后台端独立 Token，本项目请求拦截器会写入 `Token` 请求头。
- 后台端根据登录角色展示不同工作台数据，真正的角色权限和数据范围以后端网关及各服务校验为准。
- 页面刷新时先恢复本地展示快照，再调用后端 Token 校验决定是否批量加载管理数据。

## 本地命令

```bash
npm install
npm run dev
npm run build
```

默认开发地址由 Vite 输出，一般为 `http://localhost:5174`。
