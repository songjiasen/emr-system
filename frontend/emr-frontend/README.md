# emr-frontend

患者端前端项目，负责患者注册登录、首页、医生列表、预约挂号、个人中心、病历查看、资讯和留言板。

## 当前实现范围

- 患者注册、登录、注销、Token 校验、修改密码。
- 首页医生和科室信息展示，患者预约挂号、预约列表和取消预约。
- 患者查看自己的病历、处方、检查申请和费用，并支持未支付费用支付。
- 资讯、轮播图、留言发表和留言列表。
- AI 智能检索、智能荐药等患者端演示入口。

## 接口与会话

- 前端统一通过网关前缀 `/cl584734139` 访问后端。
- 登录成功后保存患者端独立 Token，本项目请求拦截器会写入 `Token` 请求头。
- 页面刷新时先恢复本地展示快照，再调用后端 Token 校验决定是否加载受保护资源。
- 患者端和后台端使用不同的本地存储键，避免两个端互相覆盖登录态。

## 本地命令

```bash
npm install
npm run dev
npm run build
```

默认开发地址由 Vite 输出，一般为 `http://localhost:5173`。
