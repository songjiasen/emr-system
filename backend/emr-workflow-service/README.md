# emr-workflow-service

工作流审核服务，默认端口 `8106`。

## 服务职责

- 主任审核病历。
- 主任审核医嘱。
- 主任审核检查申请。
- 管理员或主任审核病历归档申请。
- 记录审核状态、审核意见和审核历史。

## 对应需求

- `FR-WF`: 工作流模块。
- `FR-ORDER-06`: 医嘱审核。
- `FR-TEST-04`: 检查申请审核。
- `FR-ARCHIVE-03`: 归档审核。

## 主要数据

- `shenherenwu`
- `shenhejilu`

## 当前实现说明

- 审核任务、审核记录已使用 MySQL/H2 持久化。
- 通过网关访问时，工作流创建、列表、审核和审核记录查询只允许主任、管理员、超级管理员访问。
- 同一 `businessType + businessId` 在 `pending` 状态下不允许重复创建审核任务。
- 审核成功时会按业务类型回写下游服务：医嘱、检查申请、病历归档已接回写；`medical_record` 先只保留工作流留痕。
- 若下游业务回写失败，当前审核接口会返回 `502`，并保持任务状态和审核记录不落库，避免假成功。
- 为兼容服务内部回调和单服务测试，无可信身份头的直连请求仍可按原业务参数执行；正式前端入口统一走网关。
