# emr-user-service

用户与科室服务，默认端口 `8102`。

## 服务职责

- 管理员、医生、患者、护士、主任等用户资料维护。
- 医生详情、科室归属、擅长领域维护。
- 科室类型列表、新增、编辑、删除。

## 对应需求

- `FR-USER`: 管理员、医生、患者、角色管理。
- `FR-DEPT`: 科室管理。

## 主要数据

- `users`
- `yisheng`
- `huanzhe`
- `keshileixing`

## 当前实现说明

- 所有用户、科室、医生数据已使用 MySQL/H2 持久化。
- `/doctors` 与 `/doctors/{id}` 启动时会自动补两条演示医生数据，兼容现有前端默认展示和测试用例。
- 通过 `/user-management/{type}` 创建账号时，若未传 `password`，服务会自动写入默认初始密码 `123456` 的 BCrypt 哈希值。
- 非医生/患者类账号写入 `users` 表，医生写入 `yisheng` 表，患者写入 `huanzhe` 表。
- 医生和科室公开查询可匿名访问；用户管理类接口应通过网关携带 `Token`，由网关先完成角色访问控制。
