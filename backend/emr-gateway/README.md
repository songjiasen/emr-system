# emr-gateway

API 网关服务，默认端口 `8080`。

## 服务职责

- 统一承接前端患者端和后台端请求。
- 根据路径转发到对应微服务。
- 处理跨域、Token 鉴权、角色访问控制、可信身份头注入和写操作审计。
- 保留 `/cl584734139` 兼容前端原接口前缀。

## 对应文档

- 概要设计文档中的认证拦截器、REST API 统一入口。
- 微服务实现中的统一入口层。

## 当前实现说明

- 公开接口包括登录、患者注册、忘记密码、健康检查、医生/科室/资讯/轮播图查询。
- 受保护接口需要请求头 `Token: <登录返回的 token>`；当前不使用 `Authorization: Bearer` 格式。
- 网关会先清理客户端伪造的 `X-User-Id`、`X-Username`、`X-Role-Code`、`X-User-Table`，再通过 `emr-auth-service` 校验 Token 并重新注入可信身份头。
- 患者、医生、护士、主任、管理员按最小权限访问各业务模块；管理员和超级管理员拥有全模块权限。
- 受保护写请求成功后会向 `emr-system-service` 发布操作审计日志，避免各业务服务重复记录网关层信息。
