# emr-clinical-service

诊疗服务，默认端口 `8105`。

## 服务职责

- 医生录入、编辑、删除、查询医嘱。
- 护士执行已审核医嘱并记录执行情况。
- 医生开具处方，患者查看处方。
- 医生提交检查申请，维护检查申请信息。

## 对应需求

- `FR-ORDER`: 医嘱管理。
- `FR-PRES`: 开药/处方管理。
- `FR-TEST`: 检查项目。
- `FR-WF-04`: 医嘱执行工作流。

## 主要数据

- 医嘱相关表
- 医嘱执行记录表
- `kaifang`
- `jianchaxiang`

## 当前实现说明

- 医嘱、医嘱执行记录、处方、检查申请已使用 MySQL/H2 持久化。
- 医生通过网关创建医嘱、处方、检查申请时只能使用自己的 `doctorId`；未传医生信息时会从可信身份头补齐。
- 患者查询处方和检查申请时只能查看自己的数据；医生列表默认收敛到自己的诊疗数据。
- 医嘱必须审核通过后才能执行；执行成功后会新增执行记录并把医嘱状态更新为 `executed`。
- 护士执行医嘱时需要护士或管理员角色；未传执行护士信息时会从可信身份头补齐。
- 医嘱和检查审核结果回写只允许主任或管理员通过网关触发；内部工作流回调在无身份头场景下仍保持兼容。
- 处方删除改为软取消，写 `status=cancelled`；检查申请在录入结果内容后可从 `approved` 更新为 `finished`。
- 医嘱、处方、检查列表均支持按患者、医生、状态、病历 ID 等常用条件过滤。
