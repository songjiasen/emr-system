# emr-visit-service

就诊流程服务，默认端口 `8103`。

## 服务职责

- 患者预约挂号。
- 预约列表、详情、取消预约。
- 护士分诊建档。
- 入院登记、病房分配、出院办理。

## 对应需求

- `FR-APPT`: 预约挂号。
- `FR-IP`: 住院管理。
- `FR-WF-01`: 分诊建档。

## 主要数据

- `yuyueguahao`
- `fenzhenjiandang`
- `ruyuanxinxi`
- `chuyuanxinxi`

## 当前实现说明

- 预约挂号主链路已切换为数据库持久化，创建、列表、详情、取消都会真实读写 `yuyueguahao`。
- 预约编号仍以 `APPT` 开头，便于和原有前端展示、测试断言保持兼容。
- 患者通过网关访问预约接口时只能创建、查询和取消自己的预约；医生只能查询自己关联的预约。
- 分诊建档、入院登记、出院办理现已切换为数据库持久化，分别读写 `fenzhenjiandang`、`ruyuanxinxi`、`chuyuanxinxi`。
- 分诊、入院、出院接口仍保留 `businessNo` 返回字段，兼容现有前端展示和测试断言。
- 护士创建分诊、入院、出院记录时，如果请求体未传护士或操作人信息，会优先使用网关注入的可信身份头补齐。
- 护士查询分诊记录时默认按自己的 `nurseId` 收敛，管理员仍可做全量查询。
- 入院登记增加床位占用校验；同一 `wardNo + bedNo` 在 `in_hospital` 状态下不能重复登记。
- 出院办理会同步更新对应入院记录为 `discharged`，并拦截同一 `admissionId` 的重复出院。
