# emr-system-service

系统内容服务，默认端口 `8108`。

## 服务职责

- 病历资讯发布、编辑、删除、查看。
- 留言板发表、回复、删除。
- 菜单管理、轮播图配置、系统配置。
- 操作日志记录与查询。

## 对应需求

- `FR-NEWS`: 病历资讯。
- `FR-MSG`: 留言板。
- `FR-SYS`: 系统管理。
- 非功能需求中的操作日志审计。

## 主要数据

- `news`
- `messages`
- `carousels`
- `menu`
- `config`
- `syslog`

## 当前实现说明

- 资讯、留言、轮播图、菜单、配置、操作日志均已切到 MySQL 持久化。
- 留言发表通过网关访问时会使用可信身份头写入留言人信息，避免前端伪造用户身份。
- 患者查询留言默认只看自己的留言；留言回复只允许医生、护士、主任、管理员、超级管理员等工作人员角色。
- 操作日志字段与网关审计口径对齐，保存用户、角色、请求方法、请求参数、IP、耗时等信息。
- `deploy/mysql/init/08-emr-system.sql` 已补齐当前接口实际使用的 `category`、`publish_status`、`title`、`carousels` 等字段和表。
